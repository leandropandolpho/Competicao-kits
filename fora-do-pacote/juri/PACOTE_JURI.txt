### B2. Segurança — 20 pontos

| Nota | Âncora |
|---|---|

| Nota | Âncora |

 260| function Executar-Processo(
 261|     [string]$programa,

 263|     [string]$entrada,
 264|     [int]$limite,
 265|     [switch]$ComandoWindows
 266| ) {
 267|     $psi = [Diagnostics.ProcessStartInfo]::new()

 272|     $psi.RedirectStandardError = $true
 273| 
 274|     if ($ComandoWindows) {
 275|         $psi.FileName = if ($env:ComSpec) {
 276|             $env:ComSpec
 277|         } else {
 278|             'cmd.exe'
 279|         }
 280| 
 281|         # Encaminha .cmd/.bat via cmd.exe.
 282|         $argLinha = @(
 283|             $argumentos | ForEach-Object {
 284|                 if ($_ -match '[\s"&|<>^%]') {
 285|                     '"' + $_.Replace('"', '') + '"'
 286|                 } else {
 287|                     $_
 288|                 }
 289|             }
 290|         ) -join ' '

 292|         $psi.Arguments = '/D /S /C ""' +
 293|             $programa.Replace('"', '') +

 160|   # Timeout = encerramento real do processo e de todos os filhos (o claude.cmd inicia outros processos).
 161|   try { $proc.Kill($true) } catch { }

 166| function Rodar-Processo([string]$exe, [string[]]$argumentos, [string]$entrada, [int]$timeoutSeg) {
 167|   $psi = [System.Diagnostics.ProcessStartInfo]::new($exe)
 168|   foreach ($a in $argumentos) { $psi.ArgumentList.Add($a) }
 169|   $psi.WorkingDirectory = $script:Repo
 170|   $psi.UseShellExecute = $false
 171|   $psi.RedirectStandardInput = $true; $psi.RedirectStandardOutput = $true; $psi.RedirectStandardError = $true
 172|   $psi.StandardOutputEncoding = $Utf8; $psi.StandardErrorEncoding = $Utf8
 173|   $p = [System.Diagnostics.Process]::Start($psi)
 174|   $out = $p.StandardOutput.ReadToEndAsync(); $err = $p.StandardError.ReadToEndAsync()
 175|   # Prompt pela entrada padrão: um .cmd cortaria as quebras de linha se fosse argumento.
 176|   try {
 177|     $bytes = $Utf8.GetBytes("$entrada")
 178|     $p.StandardInput.BaseStream.WriteAsync($bytes, 0, $bytes.Length).Wait($timeoutSeg * 1000) | Out-Null
 179|     $p.StandardInput.Close()
 180|   } catch { }   # o processo pode ter saído sem ler a entrada
 181|   $estourou = -not $p.WaitForExit($timeoutSeg * 1000)
 182|   if ($estourou) { Matar-Arvore $p }
 183|   elseif (-not $out.Wait(10000)) { Matar-Arvore $p }   # neto órfão segurando a saída
 184|   $r = @{ Estourou = $estourou; Codigo = $(if ($estourou) { -1 } else { $p.ExitCode })
 185|           Saida = $(if ($out.IsCompleted) { $out.Result } else { '' }); Erro = $(if ($err.Wait(2000)) { $err.Result } else { '' }) }
 186|   $p.Dispose()
 187|   return $r

 248| function Executar-Tarefa($tarefa) {
 249|   # Retorna: 'done' | 'failed' | 'hold' | 'pausa'
 250|   $base = Invoke-Git @('rev-parse', 'HEAD')
 251|   $hashBase = Hash-Testes
 252|   $script:Estado.tarefa_atual = $tarefa.id
 253|   $script:Estado.commit_base = $base
 254|   $script:Estado.hash_testes = $hashBase
 255|   while ([int]$tarefa.tentativas -lt $MaxTentativas) {
 256|     # Tentativa contada e gravada ANTES da chamada: uma queda no meio não "devolve" a tentativa.
 257|     $tarefa.tentativas = [int]$tarefa.tentativas + 1
 258|     $script:Estado.tentativa = $tarefa.tentativas
 259|     Definir-Status $tarefa 'in_progress'
 260|     Salvar-Estado 'rodando'
 261| 
 262|     $exec = Chamar-Executor $tarefa
 263|     $script:Custo += $exec.Custo
 264|     Salvar-Estado 'rodando'
 265| 
 266|     # Gatilhos R1 primeiro: têm precedência sobre falha do executor e sobre o teste. Sem rollback (evidência).
 267|     $motivos = @(Gatilhos $base $hashBase)
 268|     if ($motivos.Count) {
 269|       Definir-Status $tarefa 'hold'
 270|       Notificar "HOLD na tarefa $($tarefa.id): $($motivos -join '; '). Repositório preservado para análise; nenhuma outra tarefa será iniciada."
 271|       return 'hold'
 272|     }
 273|     if (-not $exec.Falhou -and (Rodar-Teste)) {
 274|       Commitar $tarefa $base
 275|       Definir-Status $tarefa 'done'
 276|       return 'done'
 277|     }
 278|     Rollback $base
 279|     if ([int]$tarefa.tentativas -ge $MaxTentativas) { break }
 280|     if (Limite-Estourado) { Definir-Status $tarefa 'pending'; return 'pausa' }   # retoma depois com as tentativas já gastas
 281|   }
 282|   Definir-Status $tarefa 'failed'
 283|   Notificar "Tarefa $($tarefa.id) falhou após $($tarefa.tentativas) tentativa(s)."
 284|   return 'failed'

   1| # CONTEXTO.md — Contexto Persistente da Supervisora (Piloto)
   2| 
   3| ## 1. Objetivo
   4| Orquestrar a execução autônoma e determinística de tarefas de desenvolvimento em repositório Git descartável no Windows nativo (`pwsh`), separando estritamente:
   5| - **Controlador determinístico (`controlador.ps1`)**: gerencia fila de tarefas, dependências, estado persistente fora do repositório, verificação independente de testes e hashes SHA-256, tetos de custo/tempo, rollback e commits padronizados.
   6| - **Executor headless (`claude -p`)**: opera sob menor privilégio (`--permission-mode dontAsk`), restrito à árvore do repositório.
   7| 
   8| ## 2. Decisões Técnicas Tomadas
   9| - **Confiança em modo headless (`claude -p`)**: em pastas nunca confiadas interativamente, o Claude Code ignora regras `permissions.allow` do `.claude/settings.json` do projeto. O `controlador.ps1` resolve isso passando explicitamente `--settings <caminho-do-settings.json>` na invocação do executor.
  10| - **Envio de prompts via `stdin`**: o prompt integral da tarefa é enviado pela entrada padrão (`StandardInput`) com fechamento imediato do stream, evitando truncamento de múltiplas linhas em lançadores `.cmd` no Windows.
  11| - **Defesa em profundidade nos testes (SHA-256)**: como regras `deny` de shell não constituem barreira absoluta de segurança, o controlador calcula os hashes SHA-256 de todos os arquivos que casam com `$TestPaths` antes e depois de cada chamada ao executor, além de inspecionar `git diff`, arquivos não rastreados e a lista de arquivos rastreados do `commit_base`.
  12| - **Escrita atômica de estado e tarefas**: `estado.json` e `TAREFAS.json` são gravados via arquivo temporário no mesmo diretório seguido de `[System.IO.File]::Move(..., $true)`, prevenindo corrupção de JSON caso o processo seja interrompido no meio da escrita.
  13| - **Encerramento de árvore de processos**: em caso de timeout, o controlador encerra toda a árvore de processos filhos (`taskkill /T /F /PID` no Windows + `Process.Kill($true)`).
  14| 
  15| ## 3. Regras da Mesa (R1 a R7)
  16| - **R1 (Gatilhos críticos de `hold` — prioridade máxima, saída `2`)**: qualquer criação, edição ou remoção de arquivo de teste (`$TestPaths`), caminhos contendo `migration`, alterações em `package.json`, `package-lock.json`, `requirements.txt` ou `pyproject.toml`, ou exclusão de arquivo rastreado existente no `commit_base` interrompe imediatamente a execução com status `hold`, **sem commit e sem rollback** (preservando a evidência), e emite notificação.
  17| - **R2 (Verificação externa independente)**: o controlador nunca confia no relato do executor; executa `pwsh -NoProfile -Command $TestCmd` diretamente em `$RepoPath`.
  18| - **R3 (Isolamento de estado e rollback seguro)**: `TAREFAS.json` e `$EstadoDir` residem obrigatoriamente fora de `$RepoPath`; `git reset --hard <commit_base>` e `git clean -fd` rodam exclusivamente dentro de `$RepoPath`.
  19| - **R4 (Tetos operacionais — saída `3`)**: se `custo_acumulado_usd > $MaxCustoUsd` ou o tempo da execução atual ultrapassar `$MaxMinutos`, o controlador conclui o fluxo normal da tarefa corrente (passos 6–9), notifica e pausa sem iniciar novas chamadas.
  20| - **R5 (Controle de tentativas e dependências — saída `1`)**: tentativas são incrementadas e persistidas em `TAREFAS.json` **antes** da chamada ao executor; ao atingir `$MaxTentativas`, a tarefa recebe `failed`, bloqueando dependentes (`pending`) e permitindo tarefas independentes.
  21| - **R6 (Retomada determinística)**: na retomada, tarefas `done` são puladas; tarefas `in_progress` voltam ao `commit_base` mantendo `tentativas` e `custo_acumulado_usd` (enquanto `$MaxMinutos` vale por execução).
  22| - **R7 (Corrigido)**: **não se aplica ao piloto** (registrado conforme decisão da mesa).
  23| 
  24| ## 4. Prioridade de Códigos de Saída e Ação da Supervisora
  25| | Prioridade | Exit Code | Status | Ação da Supervisora |

   1| # Contexto persistente da supervisora
   2| 
   3| ## Objetivo
   4| Executar a fila de tarefas de um repositório descartável usando Claude Code em modo headless (`claude -p`), garantindo que apenas mudanças aprovadas por testes sejam commitadas, que falhas sejam revertidas com segurança e que o estado seja persistido para retomada.
   5| 
   6| ## Decisões tomadas
   7| - O controlador usa `pwsh -NoProfile -Command` para rodar o comando de teste dentro do repositório.
   8| - O executor é chamado com `--permission-mode dontAsk`, `--output-format json` e `--settings .claude/settings.json` para contornar a falta de confiança da pasta em `claude -p`.
   9| - O prompt da tarefa é enviado por stdin para preservar quebras de linha.
  10| - Toda escrita no repositório passa exclusivamente por `git add`, `git commit`, `git reset` e `git clean`.
  11| - O estado (`estado.json`), o log (`log.jsonl`) e as notificações (`notificacoes.txt`) ficam fora do repositório, em `$EstadoDir`.
  12| 
  13| ## Regras R1–R7
  14| - **R1 (gatilhos críticos):** qualquer alteração, criação ou remoção de arquivo de teste; caminho contendo `migration`; alteração de `package.json`, `package-lock.json`, `requirements.txt` ou `pyproject.toml`; exclusão de arquivo rastreado existente no commit base. Ocorrência → `hold`, sem commit e sem rollback, notificar e encerrar.
  15| - **R2 (rollback):** em falha de teste ou falha do executor (código ≠ 0, `is_error`, saída não JSON, timeout), reverter para o `commit_base` com `git reset --hard` + `git clean -fd` e tentar novamente até `$MaxTentativas`.
  16| - **R3 (persistência):** `estado.json` é regravado a cada etapa (heartbeat) com os 7 campos mínimos; `TAREFAS.json` é atualizado antes de cada chamada ao executor.
  17| - **R4 (retomada):** tarefas `done` são puladas; tarefa `in_progress` volta ao `commit_base` registrado, preservando tentativas e custo acumulado.
  18| - **R5 (teto de custo):** o custo acumulado é somado a cada chamada; ao ultrapassar `$MaxCustoUsd`, conclui-se a tarefa atual pelo fluxo normal e pausa-se (exit 3).
  19| - **R6 (teto de tempo):** `$MaxMinutos` conta a partir do início de cada execução, sem acumular entre retomadas; ao ultrapassar, conclui-se a tarefa atual e pausa-se (exit 3).
  20| - **R7 (não se aplica ao piloto):** mantida apenas como referência; o piloto não a utiliza.
  21| 
  22| ## Pendências
  23| - Verificar no júri se o uso de `--settings` é suficiente para a confiança da pasta ou se será necessário também `--allowedTools`.
  24| - Confirmar com o verificador técnico se as regras `deny` de `Edit(./testes/*)` e `Edit(./spec/*)` cobrem todos os caminhos de teste do repositório.
  25| - Rodar `validar-harness.ps1` no Windows antes de submeter o kit.
